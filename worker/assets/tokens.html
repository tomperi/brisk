Site tokens

Long-lived tokens for CI and scripts. Each one works only on the sites it names, with the scopes it names, until someone disables or deletes it.

new token

Tokens are created from the CLI with your personal login, never from this page: every site is served from this origin, so a page here could read a secret it creates.

scopes
read
view the site, its files and its db
write
first deploy, db inserts, file uploads
update
redeploy over the live site, db edits
delete
delete the site, db deletes
